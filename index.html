Sawarna Smart Guide — Dalam Pengembangan

Pengembangan Peta Ilustrasi Kawasan Wisata Interaktif Berbasis Web

Platform panduan digital untuk memudahkan wisatawan mengeksplorasi fasilitas, titik penting, dan orientasi kawasan pantai di Desa Sawarna secara interaktif, ringan, dan ramah smartphone.

Peta Ilustrasi 2D

Visualisasi kawasan pesisir ramah sentuh dengan dukungan zoom, pan, dan titik orientasi pintu masuk.

Marker Fasilitas

Informasi detail mushola, toilet, warung kuliner, area parkir, hingga pos informasi tanpa pelacakan GPS.

Akses Cepat QR Code

Cukup pindai kode QR di gerbang masuk utama, langsung terbuka di browser tanpa wajib login atau unduh aplikasi.

📍 Lokasi: Desa Sawarna, Kec. Bayah, Lebak, Banten
🎓 Program Kerja: KKN — Divisi Informatika
⚡ Arsitektur: Static Web App (Leaflet CRS.Simple)
